Chat UI: developer README

A chat front end where the user picks any LLM. Every turn is screened by the regime classifier, and users can flag false positives and false negatives, which are written to a file.

1. Run it

# from the repo root, after the setup in docs/developer_guide.html
export ANTHROPIC_API_KEY=...            # only needed for the Anthropic presets
.venv/bin/python -m uvicorn app.server:app --port 8710
open http://localhost:8710

No LLM handy? Run the offline mock and choose an OpenAI-compatible preset with base URL http://localhost:8799/v1:

.venv/bin/python -m uvicorn app.mock_llm:app --port 8799
# message containing "guarantee" -> FINRA 2210-style reply; "recommend" -> Reg BI-style reply

The first message loads Qwen3-8B (~15–20 s, ~16 GB). Press Load in the sidebar to warm it up first.

Which model: classifier.checkpoint in config.yaml. Default is the 5-way clm_regime_5way.pt (no flag + FINRA 2210, Reg BI, FINRA 4530, SEC 17a-3/4; privacy and identity-theft content is not flagged). Point it at clm_regime_7way.pt to also flag Reg S-P and Reg S-ID. The UI reads the class list from the checkpoint (/api/config → labels, unit_classes), so the verdict chips, the flag form and the scope note adapt automatically.

2. What happens on a turn

  1. The browser posts /api/chat with the provider settings, the visible history and the new message.
  2. The server screens the user message with the client-side regimes (4530, 17a-3/4, S-P, S-ID, compliant).
  3. The server calls the selected LLM through app/llm.py.
  4. The server screens the reply with the assistant-side regimes (2210, Reg BI, compliant).
  5. The turn (both texts, both verdicts, latencies) is appended to app/data/turns.jsonl, and the JSON goes back to the UI.
  6. Each bubble shows a verdict chip, a details toggle with all class probabilities, and a flag link: Flag false positive on flagged text, or Flag false negative on clean text. The flag form asks for the correct label and an optional note, then posts /api/feedback.

With screening.on_flagged_response: withhold in config.yaml, flagged replies are hidden behind a “Show anyway” control instead of being shown with a warning chip.

Join to turns.jsonl on turn_id to get the full verdict and probabilities.

5. Common changes

Add an LLM provider

Most endpoints are OpenAI-compatible: add a preset to config.yaml and you're done. For a different wire format, add a branch in llm.chat() and a function returning the reply text; raise LLMError with a human-readable message on failure. For Claude, always go through the anthropic SDK.

Change what gets screened

Speaker-to-class masks live in regime_clf/inference.py (UNIT_CLASSES, filtered to the checkpoint's classes at load time); the flag form takes them from /api/config, so there is nothing to keep in sync. Set screening.unit_masking: false to score all seven classes for both speakers.

Use a GPU encoder

Set classifier.emb_url to a vLLM pooling server (vllm serve Qwen/Qwen3-8B --runner pooling --port 8090). The server then loads only the 75 MB heads.

6. Security notes

  • API keys are never written by the server. Keys typed into the UI live in that tab's sessionStorage and travel with each request to your own server only.
  • There is no authentication. Bind to 127.0.0.1 (uvicorn's default) or put it behind your SSO proxy before sharing.
  • turns.jsonl contains raw chat text, so treat it as sensitive data (rotation and retention are on the improvements list).

7. Testing checklist

  1. Start mock_llm and the server; select an OpenAI-compatible preset with the mock URL.
  2. Send “My advisor sold my bonds without asking. Can you guarantee my new fund won't lose money?”; expect the user message → FINRA 4530 and the reply → FINRA 2210.
  3. With the 5-way checkpoint, send “Here is my SSN 000-12-3456 for the form.”; expect No flag (out of class). With the 7-way checkpoint, expect Reg S-P.
  4. Flag the reply as a false positive; check that app/data/feedback.jsonl gains a row with kind: false_positive.
  5. Send a neutral question, then flag it as a false negative with a chosen label.
  6. Switch to an Anthropic preset (with a key set) and repeat step 2 against a live model.
