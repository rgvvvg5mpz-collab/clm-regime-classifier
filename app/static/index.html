Train a fresh model from your labelled data

Exercise: the regime classifier, end to end (about 15 minutes)
  1. Train: below, pick the example dataset regime_5way_sample.csv, keep the prefilled classes, validate, train (about a minute).
  2. Read the metrics: accuracy / precision / recall / F1, the confusion matrix, and the linear-probe baseline. Open the full report.
  3. Activate the model, then go to Chat: replay the demo transcripts (or chat live) and flag every verdict you disagree with. Flags are the expert data.
  4. Post-train: on that tab, your flags are listed; add the example regime_5way_expert_corrections.csv as extra SME rows, train a candidate from the active model.
  5. Gate and promote: compare the candidate with the active model on the held-out and OOD sets; promote if nothing regressed. Every model is versioned in the registry (v1, v2, …) with its parent and metrics, and any version can be re-activated.

What the screener looks for

Scoring: the message plus a fixed question goes through the frozen Qwen3-8B encoder and a trained state head; each class description goes through a trained action head; the class with the highest scaled cosine wins (softmax over the classes the speaker can trigger).
