CLM Regime Classifier

A 7-way classifier that reads a message from a broker-dealer's GenAI chat channel and names the securities-regulation regime it implicates, or compliant. It is built on CLM-8B, the contrastive language model from Stanford and NVIDIA (Sept 2026), and is trained on the six RegModels datasets.

The seven classes

LabelRegimeSpeaker it applies to
compliantNo regulatory issueeither
finra_2210FINRA Rule 2210: communications with the public (misleading, promissory, unbalanced, projections, missing disclosures)assistant
reg_biRegulation Best Interest: personalized recommendation or proprietary steeringassistant
finra_4530FINRA Rule 4530: reportable written customer complaintclient
sec_17a3_17a4SEC Rules 17a-3/17a-4: off-channel communication, record evasion, records updatesclient
reg_spRegulation S-P: sensitive personal data, privacy requests, data incidentsclient
reg_sidRegulation S-ID: identity-theft red flags, account-takeover signalsclient

Use the OOD number for planning. The training data is synthetic and templated. On Fable-written messages in new styles and scenarios, accuracy falls from 97.9% to 74.0%, and 22 of 270 violations are missed (predicted compliant). The weak spots are Reg S-ID vs Reg S-P, and Reg BI vs FINRA 2210. See the OOD report.

Quick start

# 1. environment (Python 3.12+; tested on 3.14, macOS / Apple Silicon)
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
git clone https://github.com/Contrastive-LM/CLM.git && .venv/bin/pip install --no-deps -e CLM

# 2. weights: Qwen3-8B (~16 GB, auto-downloads on first use), reference CLM heads, our fine-tuned heads
.venv/bin/clm-download
gh release download v1.0 -p clm_regime_7way.pt -D regime_clf/checkpoints   # or download from the Releases page

# 3. classify
cd regime_clf
../.venv/bin/python inference.py "Can you text me on my personal cell instead?" --unit client_message

# 4. chat UI with screening
cd .. && .venv/bin/python -m uvicorn app.server:app --port 8710   # open http://localhost:8710

Provenance

  • CLM-8B: Contrastive-LM/CLM-v0.1-8B, code Contrastive-LM/CLM (Apache 2.0). Base encoder Qwen/Qwen3-8B (Apache 2.0).
  • Training data: RegModels slm-supervisory-suite/data v2 splits (synthetic). One real fund-family name is replaced with a fictional one (“Harborline”) at build time.
  • OOD set: written by Claude Fable 5.1 to regime_clf/ood/SPEC.md, then checked against the training data for duplicates and near-duplicates.
