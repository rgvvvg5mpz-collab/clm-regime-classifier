CLASP

Contrastive Labelling And System-1 Prediction

A workbench for building fast text classifiers from a few hundred labelled examples, and improving them with expert feedback.

Product walkthroughgithub.com/rgvvvg5mpz-collab/clasp
The idea

System-1 classifiers: fast, cheap, single decisions

A System-1 model…

  • answers one question about a text: which class?
  • scores candidates instead of writing text
  • takes milliseconds, not seconds
  • sits beside an LLM to screen, route or triage

Typical uses

  • screening chat turns for compliance issues
  • routing support emails to the right team
  • flagging risky or out-of-scope requests
  • labelling data at scale
CLASP2
How it scores a text

Compare the text with a description of every class

Built on CLM-8B (Stanford / NVIDIA). One encoder pass per text; the heads add a fraction of a millisecond.

CLASP3
How it learns

A contrastive loss over the class descriptions

For every labelled row

  • its own class description is the positive
  • every other class is a negative
  • no hand-written negatives needed
  • only two small heads train: 19 million parameters, about a minute

What you provide

  • rows of text and label (CSV or JSONL)
  • one plain sentence describing each class
  • a negative class, "none of the above", with its own examples
  • optionally: who is speaking, user or assistant

The workflow

Four tabs, one loop

0

Curate

Prompt Claude Code to research a topic and write a labelled dataset with class definitions.

1

Train

Pick data, define the classes, validate, train, and read accuracy, precision and recall.

2

Chat & flag

Run conversations through the model and flag every verdict you disagree with.

3

Post-train

Fold the flags back in, gate the candidate against the current model, promote it.

Every model is versioned, with its parent, metrics and gate result. Any version can be switched back in.

Getting started

Clone it and run one command

git clone https://github.com/rgvvvg5mpz-collab/clasp.git
cd clasp
scripts/run_ui.sh        # sets up on first run, then http://localhost:8710

Or ask Claude Code

Open the clone and say "run the UI". The repo ships a skill for exactly that.

Needs

Python 3.10+, about 20 GB of disk, and Apple Silicon with 24 GB or a 24 GB CUDA GPU. No API key for the demo or training.
