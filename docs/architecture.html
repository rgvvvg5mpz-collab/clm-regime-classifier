4. Deployment notes

  • Memory: Qwen3-8B in bf16 needs ~16 GB. Only one process on a 24 GB Mac should hold it; stop the UI before running evaluations.
  • GPU servers: run vllm serve Qwen/Qwen3-8B --runner pooling --port 8090 and set classifier.emb_url in app/config.yaml, or pass --emb-url. The heads run on CPU in well under a millisecond.
  • Secrets: the server never writes API keys. Keys come from environment variables named in config.yaml, or from the browser tab's session storage, and are sent per request.
